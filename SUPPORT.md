# Support & Community Guidelines

Thank you for using `api-quick`! Here are the best ways to get help, report issues, and connect with the community.

## Getting Help

### Documentation & Architecture Specification
Before opening a support request, please review our official documentation and technical specifications:
- [README.md](README.md) - Getting Started, Installation, Quick Usage.
- [CONTRIBUTING.md](CONTRIBUTING.md) - Contribution Guide.

### GitHub Discussions
For general Q&A, workflow questions, or architectural suggestions:
- Use [GitHub Discussions](https://github.com/SKJUV/api-quick/discussions) to ask questions and share ideas with fellow developers.

### Issue Tracker
- **Bug Reports**: If you've found a bug, please check [Existing Issues](https://github.com/SKJUV/api-quick/issues) first. If it hasn't been reported, submit a new bug report using our issue template.
- **Feature Requests**: To suggest a new feature or improvement, open a feature request issue.

## Security Vulnerabilities

If you discover a security vulnerability within `api-quick`, please **DO NOT** create a public issue.
Instead, refer to our [Security Policy](.github/SECURITY.md) or email our core team at `security@api-quick.dev`.
